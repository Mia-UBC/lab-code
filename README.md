# lab-code
Repo for storing all (generalized) code for lab work, so I don't have to go guessing what folder it's in.

# Includes
- Code for making a euler plot (fancy venn diagram)
- Code for making an UpSet plot (for when there's too many categories for a Venn/Euler diagram)
- Code for making a Forest plot (useful when comparing the L95/U95/OR of various things)
- Code for associating a gene name with a specific variant
